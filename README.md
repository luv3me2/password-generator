# Password Generator

Мощный генератор паролей для командной строки с расширенными функциями: проверка сложности, история сохранённых паролей, гибкие настройки символов.

## Возможности

- Генерация паролей любой длины (от 4 до 100+ символов)
- Выбор типов символов:
  - Цифры (0-9)
  - Строчные буквы (a-z)
  - Заглавные буквы (A-Z)
  - Специальные символы (!@#$%^&* и др.)
- Исключение похожих символов (1, l, I, 0, O)
- Проверка сложности пароля (от "Слабый" до "Очень сложный")
- Сохранение паролей в историю с тегами сервисов
- Просмотр истории всех сгенерированных паролей
- Генерация нескольких паролей одновременно
